    39|## 怎么用？
    40|
    41|你不需要记住上面那堆公式。你只需要说人话，它就能给你整活。
    42|
    43|### 快速上手
    44|
    45|```
    46|你：用通辽语法说一下这个月加班很多
    47|它：不能说是996吧，至少也可以说是007。情况就是这么个情况，你在工位上的时间比在床上都长，
    48|    但具体是什么情况，还是要看情况。你品，你细品。
    49|
    50|你：造个歇后语，意思是"不自量力"
    51|它：蚂蚁举大象——用生命在吹牛逼
    52|
    53|你：用互联网黑话描述一下我们部门开会
    54|它：会议聚焦痛点，深度对齐颗粒度，形成从甩锅到摸鱼的生态闭环，
    55|    通过组合拳赋能每个成员的差异化赛道，最终实现团队价值的耦合。
    56|    但凡能有一点产出，也不至于一点产出也没有。
    57|```
