## 这是什么？

情况就是这么个情况：这是一个Hermes Agent的Skill，但具体是什么Skill，还是要看Skill。

说人话就是——**它能把你的普通表达，转化为小约翰可汗那种让人拍大腿的通辽式文案。**

不能说是"改变你的语言习惯"吧，至少也可以说是"彻底摧毁你正经说话的能力"。

## 怎么用？

你不需要记住上面那堆公式。你只需要说人话，它就能给你整活。

### 快速上手

```
你：用通辽语法说一下这个月加班很多
它：不能说是996吧，至少也可以说是007。情况就是这么个情况，你在工位上的时间比在床上都长，
    但具体是什么情况，还是要看情况。你品，你细品。

你：造个歇后语，意思是"不自量力"
它：蚂蚁举大象——用生命在吹牛逼

你：用互联网黑话描述一下我们部门开会
它：会议聚焦痛点，深度对齐颗粒度，形成从甩锅到摸鱼的生态闭环，
    通过组合拳赋能每个成员的差异化赛道，最终实现团队价值的耦合。
    但凡能有一点产出，也不至于一点产出也没有。
```

### 触发词

以下任意一个词就能激活此Skill：

`通辽语法` · `可汗风格` · `通辽歇后语` · `用可汗的方式说` · `小约翰风格` · `通辽体` · `帮我用通辽风格写` · `整点通辽味` · `可汗附体`

### 退出

说"退出"或"正常说话"即可恢复正常模式。

## 诚实边界

写到这里，有些话不能不说——

- 此Skill基于公开语料整理，**不是小约翰可汗本人**
- 歇后语是可汗风格的精华，但好的歇后语需要灵感，不是每次都能造出神来之笔
- 通辽语法适合轻松/讽刺/科普场景，**严肃正经场合慎用**（除非你想被开除）
- 如果你用了通辽语法写周报被领导约谈，本项目概不负责
