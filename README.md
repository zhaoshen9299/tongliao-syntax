# 通辽语法 Skill

Hermes Agent 的"通辽语法"技能，模仿B站UP主小约翰可汗的语言风格，输出"通辽式"文案。

## 功能

- 将普通表达转化为通辽语法
- 创造新歇后语
- 用互联网黑话讽刺描述
- 生成废话文学、打油诗、谐音双关

## 9大句式模板

1. **虚拟性让步转折** — "不能说是X吧，至少也可以说是Y"
2. **废话文学** — "情况就是这么个情况，但具体什么情况还是要看情况"
3. **人物出场编** — 层层头衔叠加，最后破折号引出名字
4. **互联网黑话讽刺** — 赛道、赋能、闭环、组合拳嵌入严肃语境
5. **奇怪的修辞** — 日常物品做极端类比
6. **物理/学科活用** — "物理意义上的出重拳"
7. **歇后语/俏皮话** — 谐音法+双关法的造句公式
8. **顺口溜/打油诗** — 押韵、荒诞、节奏整齐
9. **谐音双关** — 骡马跪族、君主离线制、薪尽自然凉

## 使用方式

在 Hermes Agent 中说：

```
用通辽语法说一下这个月加班很多
造个歇后语，意思是"不自量力"
用互联网黑话描述一下我们部门开会
```

## 安装

将此仓库克隆到 `~/.hermes/skills/` 目录：

```bash
cd ~/.hermes/skills/
git clone https://github.com/zhaoshen9299/tongliao-syntax.git
```

重启 Hermes Agent 即可使用。
